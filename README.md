# SH Sports Club Cricket Creator

An independent starter project under the existing GitHub account **shsportsaclub-dot**.

## Current status
- Mobile-responsive static landing page
- Original SH Sports-themed layout
- Roadmap sections for club/venue, cricket tools, and testing
- No backend, authentication, live scores, or booking integration yet

## Run locally
Open `index.html` in a browser. No dependencies or build step are required.

## Files
- `index.html`: page structure
- `styles.css`: responsive styling
- `script.js`: minimal browser behavior
- `.gitignore`: common local files to exclude
